# Casa de São Francisco — aplicativo para Android

Instalador oficial do aplicativo da Casa de São Francisco para celulares Android.

**Baixar a versão mais recente:**
https://github.com/marcosavila4634-lgtm/casadesaofrancisco-app-download/releases/latest/download/CasaSaoFrancisco-App.apk

## Como instalar

1. Toque no link acima para baixar.
2. Quando terminar, toque no arquivo baixado.
3. Se o celular avisar sobre **fonte desconhecida**, toque em **Configurações** e ligue **Permitir desta fonte**.
4. Volte e toque em **Instalar**.

Este repositório guarda só o instalador; o código do aplicativo não fica aqui.
